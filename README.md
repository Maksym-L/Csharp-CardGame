# Csharp-CardGame
A logic-based card game developed in pure C#.

## Key Features
- **Pure C# Logic:** No game engine used, focusing on core programming.
- **OOP Principles:** Developed using classes, objects, and encapsulation.
- **Console Interface:** Clean and functional text-based gameplay.

## Why this project?
I built this to master C# fundamentals and logic architecture before moving on to Unity development.

## Before use
- Check the TODOs in the Program class. The project wouldn't work without it.
- If you want to take a look on the file of the Deck, the format of cards is "Name, health, damage and costs of mana".
